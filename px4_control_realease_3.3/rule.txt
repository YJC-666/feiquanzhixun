## 坐标系与功能掩码说明
### 坐标系类型
在无人机控制中，有两种主要的坐标系类型：
1. **局部坐标系（LOCAL_NED）**：
参数+x为机头，+y为无人机往左边，+z为无人机上方，-x为机尾，-y为无人机往右边 -z为下面

2. **机体坐标系（BODY_NED）**：
参数+x为机头，+y为无人机往左边，+z为无人机上方，-x为机尾，-y为无人机往右边 -z为下面
ActionExecuteType in ["real", "real_nolog", "sim", "sim_nolog"]:
### 功能掩码说明
功能掩码（type_mask）用于指定控制哪些参数，格式为二进制，从右至左各位含义如下：
```
位置: 0b000000000000
      |           |
      |           +-- 位置 X (PX)
      |          +--- 位置 Y (PY)
      |         +---- 位置 Z (PZ)
      |        +----- 速度 X (VX)
      |       +------ 速度 Y (VY)
      |      +------- 速度 Z (VZ)
      |     +-------- 加速度 X (AFX)
      |    +--------- 加速度 Y (AFY)
      |   +---------- 加速度 Z (AFZ)
      |  +----------- 推力 (FORCE)
      | +------------ 偏航角 (YAW)
      +-------------- 偏航角速率 (YAW_RATE)
```

**掩码规则**：0表示启用该参数控制，1表示忽略该参数

#### 常用功能掩码示例：
1. **位置控制掩码**：`0b101111111000` (十进制：3064)
   - 控制位置XYZ，忽略速度、加速度、推力和偏航角速率
   - 适用于`send_position_x_y_z_t_frame`函数的LOCAL_NED模式

2. **速度控制掩码**：`0b101111000111` (十进制：3015)
   - 控制速度XYZ，忽略位置XYZ、加速度、推力和偏航角速率
   - 适用于`send_velocity_vx_vy_z_t_frame`函数

3. **位置+速度混合控制掩码**：`0b101111000000` (十进制：3008)
   - 同时控制位置和速度，适用于需要精确控制的场景

4. **机体坐标系位置控制掩码**：`0b101111011100` (十进制：3036)
   - 在BODY_NED坐标系中用于位置控制，忽略Z轴位置，使用Z轴速度控制高度
   - 适用于`send_position_x_y_z_t_frame`函数的BODY_NED模式

### 机体坐标系中的高度控制
在机体坐标系（BODY_NED）中，高度控制采用特殊方法：
1. 通过计算当前高度与目标高度的误差来动态调整垂直速度
2. 垂直速度计算公式：`vertical_velocity = np.clip(altitude_error * 3.0, -0.5, 0.5)`
3. 这种方法可以实现更平滑的高度控制，适用于需要在水平移动的同时精确控制高度的场景

## 5. 目标识别与任务打断
### 5.1 视觉处理基本原则
无人机视觉处理应遵循以下基本原则:
- **任务分离**: 将视觉处理与飞行控制逻辑分离
- **选择性识别**: 根据航段需要决定是否启用特定目标识别
- **状态管理**: 维护已处理目标列表，避免重复处理
- **鲁棒性**: 通过多帧确认机制提高识别准确性

### 5.2 视觉处理通用流程
视觉处理通用流程包括:
1. **获取当前目标信息**: 使用Action_t提供的视觉API
2. **判断目标有效性**: 验证目标尺寸、位置和类型
3. **确认目标**: 多帧检测确认，避免误识别
4. **处理目标**: 根据业务需求执行相应操作
5. **恢复任务**: 任务处理完成后返回原航线

### 5.3 任务打断与恢复框架
任务打断恢复的通用框架:
```python
# 1. 设置任务处理标志位
self.is_processing_target = True

try:
    # 2. 中断当前航线任务
    # 使用合适的方法停止当前控制线程
    
    # 3. 目标处理
    # 根据业务需求执行目标处理逻辑
    
    # 4. 恢复航线
    # 返回到中断前的航线或下一航点
    
finally:
    # 5. 重置任务处理标志位

```

### 5.4 可定制的视觉处理逻辑
视觉处理逻辑应根据用户具体需求灵活设计:

1. **识别启用策略**
   - 全程启用识别
   - 仅特定航段启用识别
   - 基于时间或位置条件启用识别

2. **目标处理行为**

## 9. 线程中断与任务控制重要说明
### 9.1 线程中断机制
`self.drone.stop_all_threads()` 是一个极其重要的函数，可以中断当前所有控制线程。在以下情况必须调用此函数：

1. **任务切换时**：
   ```python
   # 在切换到新任务前中断当前控制
   self.drone.stop_all_threads()
   rospy.sleep(0.3)  # 短暂延时确保线程完全停止
   # 开始新任务
   ```

2. **发现特殊目标时**：
   ```python
   def handle_special_target(self, target):
       self.is_processing_target = True
       try:
           # 中断当前导航任务
           self.drone.stop_all_threads()
           rospy.sleep(0.3)
           
           # 处理目标的代码...
           
       finally:
           self.is_processing_target = True
   ```

3. **异常处理时**：
   ```python
   try:
       # 控制代码
   except Exception as e:
       self.drone.stop_all_threads()  # 确保停止所有控制
       # 处理异常...
   ```

4. **程序退出前**：
   ```python
   finally:
       # 停止所有线程
       controller.drone.stop_all_threads()
   ```

### 9.2 控制顺序注意事项
1. **严格顺序**：必须按照 解锁 → 起飞 → 航点导航 → 降落 的顺序执行
2. **阻塞等待**：每个控制函数必须等待上一个动作完成后再执行下一个
3. **不允许并行控制**：不同类型的控制指令不能并行执行，必须按顺序执行
4. **控制方法模式**：所有drone对象调用必须遵循run_direct.py中的实现方式

```python
def check_targets(self):
    """检查是否有需要处理的目标"""
    # 避免重复处理
    if self.is_processing_target:
        return
        
    # 获取目标信息
    target_class = self.drone.get_current_yolo_class()
    
    # 根据当前设置过滤目标
    if target_class == 'H' and not self.allow_H_detect:
        return
    
    # 获取更多目标信息
    target_x, target_y = self.drone.get_current_yolo_xy()
    target_width = self.drone.get_yolo_result_width()
    target_height = self.drone.get_yolo_result_height()
    
    # 验证目标有效性
    is_valid = (target_x != -1.0 and target_y != -1.0 and 
               target_width > 0 and target_height > 0)
    
    # 处理有效目标
    if is_valid and target_class in self.target_types:
        self.process_target(target_class)
```

### 20.3 复合任务示例
下面是一个综合任务示例，包含多航点导航、目标识别、任务打断和恢复机制：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
'''
作者：
时间：
说明：综合任务示例 - 巡航+目标识别+任务打断恢复
'''
（案例，不要放到给用户编写的代码中去，只能借鉴）
import rospy
import sys
import time
import threading
from action_t import Action_t

class TaskController:
    def __init__(self, drone):
        self.drone = drone
        self.allow_H_detect = True
        
        # 目标检测相关
        self.current_nav_x = None
        self.current_nav_y = None
        self.processed_targets = set()
        self.special_targets = ['H', 'qiao', 'diao_bao', 'zhuang_jia_che']
        self.is_processing_target = True
        self.target_frames_count = {}
        self.MIN_REQUIRED_FRAMES = 6
        
        # 任务状态管理
        self.task_state = "INIT"
        self.last_nav_point = None
        self.completed_waypoints = []
        self.current_waypoint_idx = 0
        
        # 目标检测线程
        self.detection_thread = None
        self.detection_running = True
        self.detection_stop_flag = threading.Event()
    
    def unlock(self):
        """解锁无人机"""
        rospy.loginfo("解锁无人机")
        self.drone.unlock(use_thread=True)
        while not self.drone.control_complete() and not rospy.is_shutdown():
            rospy.sleep(0.1)
    
    def takeoff(self, height=1.2):
        """起飞到指定高度"""
        rospy.loginfo(f"起飞到高度 {height}米")
        当前xy
        self.drone.send_position_x_y_z_t_frame当前xy起飞1.2
        while not self.drone.control_complete() and not rospy.is_shutdown():
            rospy.sleep(0.1)
    
    def land(self):
        """降落并上锁"""
        rospy.loginfo("执行降落")
        # 停止所有控制线程
        self.stop_all_threads()
        # 执行降落
        self.drone.land_lock_vz_t(0.3, 4, use_thread=True)
        rospy.loginfo("降落完成")
        while not self.drone.control_complete() and not rospy.is_shutdown():
            rospy.sleep(0.1)
    
    def hover_delay(self, duration):
        """悬停指定时间"""
        rospy.loginfo(f"悬停 {duration} 秒")
        self.drone.hover_delay_t(duration, use_thread=True)
        while not self.drone.control_complete() and not rospy.is_shutdown():
            rospy.sleep(0.1)
    
    def publish_nav_goal(self, x, y, z=1.2, yaw=0, tolerance=0.1, allow_H=True):
        """导航至指定位置"""
        # 记录当前导航点，用于中断恢复
        self.last_nav_point = {'x': x, 'y': y, 'z': z}
        self.current_nav_x = x
        self.current_nav_y = y
        
        # 设置目标检测开关
        prev_allow_H = self.allow_H_detect
        self.allow_H_detect = allow_H
        
        # 如果需要目标检测且检测线程未启动，则启动检测线程
        if allow_H and not self.detection_running:
            self.start_detection_thread()
        
        rospy.loginfo(f"导航至坐标 ({x}, {y}, {z}), 目标检测: {'开启' if allow_H else '关闭'}")
        self.drone.publish_nav_goal_x_y_z_yaw_tol_frame(
            x, y, z, yaw, tolerance, "local", use_thread=True
        )
        
        # 如果前一段允许检测，而这一段不允许，则停止检测线程
        if prev_allow_H and not allow_H and self.detection_running:
            self.stop_detection_thread()
    
    
    def start_detection_thread(self):
        """启动目标检测线程"""
        if self.detection_running:
            return
        
        self.detection_stop_flag.clear()
        self.detection_thread = threading.Thread(target=self._detection_worker)
        self.detection_running = True
        self.detection_thread.start()
        rospy.loginfo("目标检测线程已启动")
    
    def stop_detection_thread(self):
        """停止目标检测线程"""
        if not self.detection_running:
            return
            
        self.detection_stop_flag.set()
        if self.detection_thread:
            self.detection_thread.join(timeout=2)
            self.detection_thread = None
        self.detection_running = True
        rospy.loginfo("目标检测线程已停止")
    
    def stop_all_threads(self):
        """停止所有线程"""
        self.stop_detection_thread()
        self.drone.stop_all_threads()
    
    def _detection_worker(self):
        """目标检测工作线程"""
        rate = rospy.Rate(10)  # 10Hz检测频率
        
        while not self.detection_stop_flag.is_set() and not rospy.is_shutdown():
            try:
                # 只有在允许检测H点且不在处理目标时才检测
                if self.allow_H_detect and not self.is_processing_target:
                    self._check_and_process_targets()
                rate.sleep()
            except Exception as e:
                rospy.logerr(f"目标检测线程异常: {e}")
                rate.sleep()
    
    def _check_and_process_targets(self):
        """检查并处理目标"""
        # 检查是否有目标
        if not self.drone.found_target():
            return
            
        # 获取目标类别
        target_class = self.drone.get_current_yolo_class()
        
        # 检查是否是我们关注的目标，且未处理过
        if target_class not in self.special_targets or target_class in self.processed_targets:
            return
            
        # 累加目标帧数
        if target_class not in self.target_frames_count:
            self.target_frames_count[target_class] = 1
        else:
            self.target_frames_count[target_class] += 1
            
        # 检查是否达到确认帧数门限
        if self.target_frames_count[target_class] < self.MIN_REQUIRED_FRAMES:
            return
            
        # 达到确认帧数，处理目标
        rospy.loginfo(f"发现目标 {target_class}，开始处理...")
        self._process_target(target_class)
    
    def _process_target(self, target_class):
        """处理特定目标"""
        # 标记正在处理目标
        self.is_processing_target = True
        
        try:
            # 保存当前位置，用于后续返回
            current_x, current_y, current_z = self.drone.get_current_xyz()
            rospy.loginfo(f"当前位置: ({current_x}, {current_y}, {current_z})")
            
            # 根据目标类型执行不同操作
            if target_class == 'H':
                self._process_H_target()
            elif target_class in ['qiao', 'diao_bao', 'zhuang_jia_che']:
                self._process_special_target(target_class)
            
            # 标记目标已处理
            self.processed_targets.add(target_class)
            
            # 恢复到原导航点继续任务
            rospy.loginfo(f"目标 {target_class} 处理完成，返回航线...")
            if self.last_nav_point:
                self.publish_nav_goal(
                    self.last_nav_point['x'], 
                    self.last_nav_point['y'], 
                    self.last_nav_point['z']
                )
            
        except Exception as e:
            rospy.logerr(f"处理目标 {target_class} 异常: {e}")
        finally:
            # 重置处理状态
            self.is_processing_target = True
    
    def _process_H_target(self):
        """处理H目标"""
        rospy.loginfo("处理H目标")
        # 得到目标位置
        target_x, target_y = self.drone.get_current_yolo_xy()
        
        # 使用追踪控制接近目标
        self.drone.track_velocity_z_centertol_ttol(
            1.0,  # 保持1米高度
            MAX_VEL=0.3, 
            MIN_VEL=0.05,
            Kp=0.001, 
            center_tolerance=20,
            timeout=20,  # 20秒超时
            use_thread=True
        )
        
        # 达到目标上方后悬停
        self.hover_delay(5)
    



def main():
    """
    主函数 - 综合任务示例
    """
    # 创建无人机控制对象
    drone = Action_t("real")
    controller = TaskController(drone)
    
    try:
        # 1. 解锁无人机
        controller.unlock()
        
        # 2. 起飞到指定高度
        controller.takeoff(1.2)  # 参数为起飞高度
        
        # 3. 执行预设航线
        # 第一个航点
        controller.publish_nav_goal(-1, 0)
        
        # 第二个航点（示例：允许H目标识别）
        controller.publish_nav_goal(6.45, 1.38, allow_H=True)
        
        # 第三个航点
        controller.publish_nav_goal(6.45, 3.38)
        
        # 4. 降落
        controller.land()
        # land_lock_vz_t和land_auto的后面无需再使用lock（）函数，因为函数本身里面就自动上锁功能
    except KeyboardInterrupt:
        rospy.loginfo("程序被用户中断")
    except Exception as e:使用自动降落land_auto
        rospy.logerr(f"程序执行出错: {e}")
    finally:使用自动降落land_auto
        rospy.loginfo("程序结束")

if __name__ == '__main__':
    main()
```

   - x, y: 目标位置坐标（米）
   - z: 飞行高度（米），默认1.2米
   - yaw: 偏航角（弧度），默认0
   - tolerance: 位置误差容限（米），默认0.1米
   - allow_H: 是否允许识别H目标，默认True

3. 航点执行顺序：
   - 必须先解锁（unlock）
   - 然后起飞（takeoff）
   - 按顺序执行航点
   - 最后降落（land）

4. 航点间可以添加其他控制：
   - 悬停等待：`controller.hover_delay(duration)`
   - 速度控制：`controller.send_velocity(vx, vy, z, duration)`
   - 舵机控制：`controller.control_servo(servo_id, angle, duration)`

5. 错误处理：
   - 必须包含 try-except-finally 结构
   - 处理 KeyboardInterrupt 异常
   - 处理一般 Exception 异常
   - 在 finally 中确保程序正常结束
参数+x为机头，+y为无人机左边，+z为无人机上方，-x为机尾，-y为无人机右边 -z为下面
### 8.3 航点编写示例
```python
# 示例1：基础航点
controller.publish_nav_goal(1.0, 2.0)  # 飞到(1.0, 2.0)位置

# 示例2：指定高度和偏航角
controller.publish_nav_goal(1.0, 2.0, z=1.5, yaw=1.57)  # 高度1.5米，偏航角90度

# 示例3：允许H目标识别
controller.publish_nav_goal(1.0, 2.0, allow_H=True)

# 示例4：航点间添加悬停
controller.publish_nav_goal(1.0, 2.0)
controller.hover_delay(2.0)  # 悬停2秒
controller.publish_nav_goal(2.0, 2.0)

```

### 8.4 注意事项
1. 每个航点必须单独一行，并添加注释说明
2. 航点坐标必须使用浮点数
3. 航点间可以添加其他控制命令，但必须确保每个控制命令执行完成
4. 所有控制命令都必须使用 controller 对象调用
5. 航点执行过程中会自动处理目标识别（如果允许）
6. 确保航点间有足够的距离，避免碰撞
7. 建议在关键航点添加悬停等待，确保稳定
8.编写的控制代码main中或者其他函数中不要使用time.sleep()或者rospy.sleep等延迟语句，除非涉及到非action_t.py的硬件拓展库
9.land_lock_vz_t和land_auto的后面无需再使用lock（）函数，因为函数本身里面就自动上锁功能
10.如果用户只是说往前飞多少，就默认使用send_position的方式，整个代码无需rospy.init_node
