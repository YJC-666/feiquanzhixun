# 野生动物巡查系统

## 系统概述

这是一个基于Python3和ROS的野生动物巡查系统，用于无人机自主巡查450cm×350cm的区域。系统能够：

- 手动选择3个禁飞区
- 自动规划避开禁飞区的巡查航线
- 遍历所有9×7网格方格
- 安全降落到指定目标点
- 通过ROS话题发布任务状态

## 系统参数

- **巡查区域**: 450cm × 350cm (9×7网格)
- **方格大小**: 50cm × 50cm
- **起降点**: B1 (左下角)
- **目标点**: A9 (右下角，红点位置)
- **飞行高度**: 1.2米
- **禁飞区数量**: 3个（手动选择）

## 文件说明

- `wildlife_survey_system.py` - 主程序文件
- `run_wildlife_survey.py` - 启动脚本
- `waypoints.yaml` - 生成的航点文件（格式：序号:x,y,z）
- `waypoints_detail.txt` - 详细航点信息

## 依赖环境

```bash
# Python包
pip install pyyaml

# ROS环境（需要预先安装）
- rospy
- std_msgs
```

## 使用方法

### 1. 启动系统
```bash
python3 run_wildlife_survey.py
```

### 2. 操作步骤
1. **选择禁飞区**: 在图形界面中点击3个方格作为禁飞区（显示为红色）
2. **规划航线**: 点击"规划航线"按钮，系统自动生成避开禁飞区的巡查路径
3. **开始任务**: 点击"开始任务"按钮，系统开始发布ROS话题
4. **停止任务**: 点击"停止任务"按钮停止任务

### 3. 界面说明
- **绿色方格**: 起降点B1
- **蓝色方格**: 目标点A9（红点位置）
- **红色方格**: 禁飞区
- **白色方格**: 可飞行区域

## ROS话题

- **话题名称**: `/mission_status`
- **消息类型**: `std_msgs/Int32`
- **发布频率**: 5Hz
- **消息内容**: 
  - `1`: 任务执行中
  - `0`: 任务未开始或已停止

## 航线规划算法

系统使用以下算法确保安全高效的巡查：

1. **A*路径规划**: 避开禁飞区寻找最优路径
2. **贪心策略**: 优先访问距离最近的方格
3. **安全降落**: 规划从最后航点到目标点的安全路径

## 注意事项

1. 必须选择3个禁飞区才能规划航线
2. 起降点和目标点不能设为禁飞区
3. 系统会自动寻找避开禁飞区的最优路径
4. 最终降落点高度为0米
5. 需要ROS环境支持话题发布功能

## 故障排除

1. **ROS初始化失败**: 检查ROS环境是否正确配置
2. **无法规划航线**: 检查禁飞区设置是否阻挡了所有路径
3. **界面无响应**: 检查tkinter是否正确安装
4. **文件保存失败**: 检查当前目录写入权限
